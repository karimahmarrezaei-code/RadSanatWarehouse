بستهٔ لخت سیستم انبارداری (بدون دیتا)
1) زیپ را در لپ‌تاپ استخراج کنید (مثلاً F:\warehouse_app)
2) در VS Code باز کنید؛ ترمینال: py setup_laptop.py   (دیتابیس خالی + migration ها)
3) اجرا: py main.py
4) ساخت exe: py build_exe.py   (خروجی در dist/WarehouseApp)
نکتهٔ مهم: هرگز پوشهٔ data سیستم دیگر را کپی نکنید؛ برای انتقال داده فقط از فرم پشتیبان‌گیری داخل برنامه استفاده کنید.
